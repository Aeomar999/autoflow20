## 1. Executive status

AutoFlow is a multi-tenant workflow-automation platform: React Flow canvas **that saves**, an **Inngest execution engine** running workflows through a topological sort with per-node executors and realtime status channels, human-in-the-loop **Approval Gates** with Inngest step resumption, multi-tenant RBAC (`OWNER`, `ADMIN`, `EDITOR`, `VIEWER`) and immutable **Audit Logging**, an envelope-encrypted credential vault with a type registry, a **Knowledge Base (pgvector)** supporting multi-format document ingestion with semantic vector similarity search via `AI_RETRIEVE`, workflow versioning with rollback, and webhook + cron triggers.

## 9. How to update this document

When you complete a task:

1. Move the item from §4 to §3 with a file-path evidence reference.
2. Close any defect in §5 that the change fixes; add any it introduces.
3. Update the §2 percentage for the affected PRD area — **only if the capability actually works end to end**, not if the code merely compiles.
4. Update the §6 milestone status.
5. Add a §8 changelog line.
6. If it is the end of a milestone, re-measure §7.

**Do not mark anything green that you have not personally exercised.** An honest progress document is the only thing standing between this project and a rebuild.
